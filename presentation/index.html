ПРОДУКТОВАЯ КОНЦЕПЦИЯ / 01

Арена переговоров.

От знания техник — к уверенности в разговоре.

Тренажёр для начинающих руководителей, специалистов по закупкам и сотрудников, готовящихся к карьерному разговору.

ПРОБЛЕМА И ЦЕННОСТЬ / 02

Теорию знают. Практики не хватает.

Реальный разговор дорог ценой ошибки. Тренинг сложно повторить в удобный момент. Арена даёт безопасную практику, последствия каждого решения и возможность переиграть ситуацию.

Одна сессия: брифинг → шесть этапов диалога → разбор → новая стратегия.

МЕХАНИКА / 03

Общие интересы сильнее ультиматумов

  • Два контекста: цена контракта и карьерное повышение.
  • На каждом этапе — три тактики, текстовая или голосовая формулировка.
  • Доверие, напряжённость и баллы отражают последствия выбора.
  • Разбор показывает собственную реплику, объяснение и более сильный вариант.
ДЕМОНСТРАЦИЯ / 04

Один тренажёр, разные условия

Откройте конструктор. Выберите сферу, сложность, тон, роль и цель. Пройдите шесть этапов, покажите голосовой ввод и разбор, затем повторите с другой стратегией.

Демо работает без регистрации и ключа. Для живых реплик тестировщик может подключить собственный ключ OpenAI в настройках.

ТЕХНИЧЕСКИЕ РЕШЕНИЯ / 05

Воспроизводимый MVP

Next.js App Router, TypeScript, Tailwind CSS, Lucide React, Framer Motion и Zustand. Сценарный движок отвечает автономно; Responses API добавляет AI-реплики, Web Speech — голосовой ввод и озвучивание, Web Audio — локальные сигналы.

Контекст, настройки и последние 50 результатов сохраняются в браузере. Оценка свободного текста — учебная эвристика, а не валидированная оценка компетенций.

ГРАНИЦЫ И РАЗВИТИЕ / 06

Сначала практика. Затем масштаб.

В MVP: два сценария, ветвление реакций, три сложности, контекст администратора, шесть этапов, голос, разбор, прогресс, светлая и тёмная темы.

Следующие шаги: проверка сценариев с тренерами, пилот в учебной группе, серверные аккаунты, защищённый серверный прокси и редактор веток.

Гипотезы для пилота: доля завершённых сессий, повторные попытки и перенос приёмов в очную ролевую игру.
