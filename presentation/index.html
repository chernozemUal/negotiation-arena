ПРОДУКТОВАЯ КОНЦЕПЦИЯ / 01

Арена переговоров.

От знания техник — к уверенности в разговоре.

Тренажёр для начинающих руководителей, специалистов по закупкам и сотрудников, готовящихся к карьерному разговору.

ПРОБЛЕМА И ЦЕННОСТЬ / 02

Теорию знают. Практики не хватает.

Реальный разговор дорог ценой ошибки. Тренинг сложно повторить в удобный момент. Арена даёт короткую безопасную практику, последствия каждого решения и возможность переиграть ситуацию.

Одна сессия: брифинг → четыре этапа диалога → разбор → новая стратегия.

МЕХАНИКА / 03

Общие интересы сильнее ультиматумов

  • Два контекста: цена контракта и карьерное повышение.
  • На каждом этапе — три тактики или собственная формулировка.
  • Доверие и очки отражают последствия выбора. Сложность меняет порог успеха.
  • Разбор показывает собственную реплику, объяснение и более сильный вариант.
ДЕМОНСТРАЦИЯ / 04

Один тренажёр, разные условия

Откройте конструктор. Выберите сферу, сложность, тон, роль и цель. Запустите практику и пройдите четыре этапа. Покажите разбор, затем повторите с ультиматумами и сравните результаты в прогрессе.

Демо работает без регистрации и ключа. Для живых реплик тестировщик может подключить собственный ключ OpenAI в настройках.

ТЕХНИЧЕСКИЕ РЕШЕНИЯ / 05

Воспроизводимый MVP

Next.js App Router, TypeScript, Tailwind CSS, Lucide React, Framer Motion и Zustand. Детерминированный сценарный движок отвечает автономно; при подключении ключа Responses API генерирует реплики собеседника. Контекст, текущая сессия и последние 50 результатов сохраняются в localStorage.

Оценка свободного текста — эвристика по признакам приёма. Это учебная обратная связь, а не валидированная оценка компетенций.

ГРАНИЦЫ И РАЗВИТИЕ / 06

Сначала практика. Затем масштаб.

В MVP: два сценария, ветвление реакций, три сложности, настройки контекста, разбор, прогресс и опциональные AI-реплики с ключом пользователя. Администратор — открытый демонстрационный интерфейс без авторизации.

Следующие шаги: проверка сценариев с тренерами, пилот в учебной группе, серверные аккаунты, защищённый серверный прокси и редактор веток.

Гипотезы для пилота: доля завершённых сессий, повторные попытки и перенос приёмов в очную ролевую игру.
